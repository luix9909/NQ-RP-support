# نظام الدعم الفني — Support Desk

مشروع منفصل تماماً عن موقع الراديو. صفحتان:
- `/` — صفحة الزبون: يكتب طلبه، يشوف دوره بالطابور والوقت المتوقع، وبعد ما يُقبل طلبه يفتح شات نصي + مكالمة صوتية مع الموظف.
- `/admin.html` — لوحة الموظفين والإدارة: تسجيل دخول بإيميل/باسوورد، الطابور، المحادثات النشطة، الأرشيف، التحليلات، وإدارة الموظفين (للمالك فقط).

## التشغيل محلياً
```
npm install
npm start
```
يفتح على `http://localhost:3001` (الزبون) و `http://localhost:3001/admin.html` (الإدارة).

**ملاحظة:** يحتاج Node.js 22 أو 24 (يستخدم `node:sqlite` المدمجة).

## الرفع على Render.com (مجاني)
1. ارفع المجلد لمستودع GitHub جديد.
2. render.com → New → Web Service → اختر الـ repo.
3. **مهم جداً:**
   - **Node Version**: اكتب `22` أو `24` (لا تستخدم 20)
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. Deploy.

رابط الزبون: الرابط الأساسي  
رابط الإدارة: الرابط + `/admin.html`

⚠️ الخطة المجانية تنام بعد خمول، والقرص غير دائم — أي إعادة نشر تمسح قاعدة البيانات والملفات المرفوعة (يرجع فقط حساب المالك).
