# نظام الدعم الفني — Support Desk

مشروع منفصل تماماً عن موقع الراديو. صفحتان:
- `/` — صفحة الزبون: يكتب طلبه، يشوف دوره بالطابور والوقت المتوقع، وبعد ما يُقبل طلبه يفتح شات نصي + مكالمة صوتية مع الموظف.
- `/admin.html` — لوحة الموظفين والإدارة: تسجيل دخول بإيميل/باسوورد، الطابور، المحادثات النشطة، الأرشيف، التحليلات، وإدارة الموظفين (للمالك فقط).

## التشغيل محلياً
```
npm install
npm start
```
يفتح على `http://localhost:3001` (الزبون) و `http://localhost:3001/admin.html` (الإدارة).

## موسيقى الانتظار 🎵
مكان الملف: `public/audio/hold-music.mp3`
حالياً فيه ملف صامت مؤقت (٣ ثواني) بس عشان الصفحة ما تعطي خطأ قبل لا ترفع ملفك. **لتفعيل موسيقاك:** احذف الملف الموجود وحط ملفك بنفس المسار وبنفس الاسم بالضبط (`hold-music.mp3`) — ما يحتاج أي تعديل بالكود.

## الرفع (Render.com — مجاني، نفس خطوات مشروع الراديو)
1. ارفع هذا المجلد لمستودع GitHub جديد (منفصل عن مستودع الراديو).
2. render.com → New → Web Service → اختر الـ repo.
3. **مهم جداً:** في Settings → Environment → Node Version اختر **20** (أو اكتب `20` في حقل Node Version). هذا يمنع انهيار better-sqlite3.
4. Build Command: `npm install` — Start Command: `npm start` — Instance Type: Free.
5. Deploy. بعد الانتهاء بيعطيك رابط مثل `https://your-app.onrender.com`.
6. رابط الزبون: نفس الرابط الأساسي. رابط الإدارة: نفس الرابط + `/admin.html`.

⚠️ نفس ملاحظة مشروع الراديو: الخطة المجانية بـ Render تنام بعد فترة خمول، وقرصها غير دائم — أي إعادة نشر تمسح `support.db` (يعني تفقد كل التذاكر والموظفين المضافين، ويرجع فقط حساب المالك). لو الأرشيف والتذاكر مهمة تبقى للأبد، نحتاج ننقلها لاحقاً لقاعدة بيانات خارجية دائمة.

## الصوت (المكالمات الصوتية)
نفس تقنية WebRTC المستخدمة بمشروع الراديو (STUN عام + TURN عام مجاني من Open Relay Project). يشتغل ممتاز على شبكات عادية، وقد يبطئ وقت الازدحام لأنه سيرفر عام مشترك.

## الرفع المستقبلي للملفات
الصور/الفيديوهات/الصوتيات اللي يرفعها الزبون تُخزَّن بمجلد `public/uploads/` — هذا المجلد أيضاً غير دائم على Render المجاني (يُمسح عند كل إعادة نشر لنفس سبب قاعدة البيانات).
